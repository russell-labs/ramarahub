What's changed on Ramara Hub, in plain language. New briefs, new answers, and corrections. Newest first.

How we decide what's logged

We log changes residents care about: new or updated briefs, new answers and corrections, new features, and fixes made when someone flags something. We don't log behind-the-scenes technical tweaks. Corrections are always logged, because owning a fix in public is how the site earns trust.

Jun 13, 2026 Correction: the sewer systems WERE once billed separately Correction

A resident provided Bylaw 2015.19, which shows Bayshore, Lagoon City, and Brechin each had separate sewer base rates in 2015–2016, later harmonized to a common rate. We had described it as one rate base throughout; that was wrong, and the brief is now corrected. We’ve since confirmed the harmonization took effect January 1, 2017 via Bylaw 2017.10, based on the 2016 Hemson Consulting rate study. Read it →
